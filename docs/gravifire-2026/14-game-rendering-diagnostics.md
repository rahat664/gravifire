## Visual and gameplay review

- Review-mode M0/M1 scenes rendered and the browser suite confirmed M0/M1/M4/M6 route/context navigation and campaign-state compatibility. No new gameplay physics or state corruption was observed.
- In review mode the fixed `REVIEW MODE · PLAYCANVAS` badge overlaps the top-right `Open NASA evidence dashboard` link. The badge is positioned fixed at the same corner with a higher z-index (`PlayCanvasMissionChrome.tsx`); `MissionScienceLink.tsx` uses absolute top/right placement. It should be resolved by moving one control or reserving a shared header layout before recording the submission demo.

Screenshots captured home, dashboard, experiment list/B1, ranking, applicability, Virtual Lab, EMBER, Mission Control, Dossier, M0 and M1. - Homepage is polished and explains the NASA evidence premise, but its strongest CTA leads to Mission Control. Dashboard is a navigation item, while the first-time user may not discover the challenge's summarize/rank/interpret path immediately. Add a primary “Open Challenge Dashboard” entry point for demo clarity.
- A custom screenshot pass showed a transient hydration-style overlay associated with injected caret-hiding during capture. A normal network-idle check subsequently returned `/applicability` with no console warning/error. No application hydration regression was reproduced; do not file as a confirmed app defect.

## Compatibility assessment and safe follow-up

Neither PlayCanvas warning justified a blocker by itself: core scenes render, all four mission routes passed the existing browser acceptance checks, and no persistent visible effect was demonstrated. The uniform warning is attributable to a project-authored shader's delayed first assignment and has a contained source fix. The `getGuid` warning is inside the installed React adapter; remediation belongs in a dependency update after upstream compatibility review, not direct installed-file edits. Recheck warning counts and gameplay after any future fix. No rendering or dependency changes were made.
