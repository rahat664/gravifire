# GRAVIFIRE PlayCanvas Prototype Asset Pack

Generated for M1 visual prototyping. All generated GLBs use **metres** and **+Y up**.

## Generated modules

- `gravifire_lab_shell_8x8.glb` — enclosed 8×8 m research-lab shell with floor panels, walls, ceiling rails/lights and doorway frame.
- `gravifire_corridor_4m.glb` — 4 m corridor module.
- `gravifire_bulkhead_door.glb` — static split bulkhead; animate leaves in-engine if desired.
- `gravifire_science_console.glb` — standing scientific console.
- `gravifire_sibal_sample_station.glb` — physical SIBAL prep/test stand visual proxy.
- `gravifire_equipment_rack.glb` — equipment/server rack.
- `gravifire_analysis_wall.glb` — physical two-screen housing for the 420 s / 70 s comparison.

These files contain no NASA source imagery or scientific values. They are presentation geometry only.

## Recommended PlayCanvas M1 arrangement

Use `gravifire_lab_shell_8x8.glb` as the room shell. Put player spawn near `(0, 0, 2.7)` facing `-Z`. Put SIBAL station near `(0, 0, 0.8)`. Equipment racks can sit on side walls. Use the analysis wall only in the final comparison bay.

## Higher-quality CC0 external candidates

Do not treat any screen, sample geometry, or visual effect in these GLBs as NASA evidence. Scientific values/text must continue to come from GRAVIFIRE runtime evidence modules.
