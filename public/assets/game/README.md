# Mission Control game assets

Reviewed visual assets are organized by role:

- `character/` — approved character GLBs and animation notes
- `environment/` — mission-specific modular environment GLBs
- `props/` — reviewed visual props
- `materials/` — authored material presets or small map sets
- `textures/` — reviewed compressed texture maps
- `hdr/` — reviewed environment lighting maps
- `audio/` — reviewed ambience and interaction sounds

M1 currently uses only the extracted Kenney Space Station Kit modules under `environment/m1/`.
